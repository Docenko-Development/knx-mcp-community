# KNX-MCP support

This repository is the public support and community space for KNX-MCP.

| Topic | Best place |
|---|---|
| General question | GitHub Discussions |
| Setup or MCP-client configuration | GitHub Discussions |
| Workflow or usage example | GitHub Discussions |
| Reproducible software defect | GitHub Issues → Bug report |
| Feature idea | GitHub Discussions or Feature request |
| Reusable skill / prompt | `skills/` + pull request |
| Release information | `docs/release-notes/` |
| Security vulnerability | **Private email** — see `SECURITY.md` |
| Commercial / confidential matter | `gerald@docenko.eu` |

## Before reporting a bug

Please check that you are using the current KNX-MCP release and include at least:

- KNX-MCP version
- ETS5 or ETS6 version
- AI/MCP client
- what you expected
- what happened instead
- reproducible steps, if possible

Do not upload an ETS project just to demonstrate a problem. Prefer a minimal, anonymised description or screenshot.

## Privacy

Public issues and discussions are visible to everyone. Remove customer names, addresses, project numbers, access keys and any other sensitive data before posting.
