# KNX-MCP 1.1.0.0 — Release 1

**October 2026 · validated by KNX · available in the KNX Online Shop · currently free of charge**

KNX-MCP 1.1.0.0 is the first public release of the ETS App.

## Highlights

- Works with **ETS5 (5.7 or later) and ETS6**.
- Connects MCP-compatible AI assistants directly to the open ETS project.
- Public Release 1 interface exposes **76 tools** for reading, analysing, navigating, exporting, project editing, telegram functions and selected bus operations.
- Natural-language group-address search helps locate addresses without knowing their numeric address first.
- Project changes use configurable permissions and are created as named ETS undo steps.
- Telegram values can be read and sent through the ETS connection; sending requires confirmation by default for every telegram.
- Device programming tools are blocked by default.
- Supports **several open ETS projects** and **several MCP clients** at the same time.
- Panel UI: English, German, Czech, Italian and Russian.
- Help: English and German.

## Privacy and connectivity

The MCP endpoint is local-only by default. KNX-MCP does not route project data through a publisher-operated cloud service. Data is provided to the MCP client chosen by the user.

Optional network access can be enabled explicitly and protected with an access key. The endpoint uses plain HTTP, so network access should be limited to a VPN or trusted network.

## Known limitations

- **ETS5 sender addresses:** telegrams captured directly by KNX-MCP do not contain a sender address. Use the ETS group monitor with KNX-MCP as decoding app when sender information is required.
- **Bus cancellation:** cancelling the bus operation of one specific device is available in ETS6 only; ETS5 can cancel all relevant operations.
- **Project history:** requires ETS project tracing. In ETS5, project tracing is provided by a separate licensed ETS app.
- **Network transport:** KNX-MCP uses plain HTTP and does not provide TLS itself.

The complete product documentation and release material distributed with the app remain authoritative for the released package.
