# KNX-MCP 1.1.0.0 — Release 1

October 2026 · validated by KNX · available in the KNX Online Shop · free of charge

First published release. 76 tools for reading and checking the project, finding addresses from plain language, changing the project with confirmation and ETS undo, bus access through the ETS connection (monitor, read, send, identify, line scan), navigation in ETS and project export. ETS5 and ETS6, several projects and several AI clients at the same time. Panel in English, German, Czech, Italian and Russian; help in English and German.

## Known limitations

- ETS5: telegrams captured by the app itself carry no sender — use a group monitor with KNX-MCP as decoding app.
- Cancelling the bus operations of a single device works in ETS6 only.
- Project history requires ETS project tracing (in ETS5 a separate licensed KNX app).
- Network access uses plain HTTP — use a VPN or trusted network.

The full release notes (PDF, English and German) are available in MyKNX with the app.
